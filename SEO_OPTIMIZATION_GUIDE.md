## 🚀 Performance Tips

### For Developers:
1. Always use WebP format for images
2. Add `loading="lazy"` to images below fold
3. Keep JavaScript bundles under 200KB
4. Minimize third-party scripts
5. Use CSS-in-JS sparingly
6. Avoid layout shifts
7. Optimize fonts loading
8. Use CDN for static assets

### For Content:
1. Keep pages under 2MB total size
2. Optimize videos (use Cloudinary)
3. Compress images before upload
4. Use appropriate image dimensions
5. Add alt text to all images
6. Write descriptive URLs
7. Use heading tags properly
8. Add internal links
